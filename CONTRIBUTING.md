# Contributing

Thank you for your interest in this book. The content is © Anji Keesari, all rights reserved (see [LICENSE](LICENSE)), so contributions are limited to reporting problems.

## Welcome

- **Typos, broken links, outdated commands, or technical errors:** open an [issue](../../issues) with the chapter name, the section, and what you expected to happen.
- **Topic requests or questions:** open an issue, or contact the author via <https://anjikeesari.com>.

## Not accepted

- Pull requests that add, rewrite, or translate content. If you'd like to translate or reuse any part of the book, ask first by email at anjkeesari@gmail.com.

## Preview the site locally

```bash
pip install -r requirements.txt
mkdocs serve
```

Before opening an issue about a build problem, confirm `mkdocs build --strict` fails on a clean checkout.
